### `> agentic_ai`

One of my biggest areas of interest is understanding what happens **after** the LLM response.

```
USER ──▶ LLM ──▶ Reason ──▶ Decide ──▶ Select Tool ──▶ TOOL/API
                                                            │
                                                            ▼
LLM ◀── CONTEXT ◀── RESULT ◀───────────────────────────────┘
 │
 ▼
ACTION
```

**Currently exploring:**

`LLM APIs` → `Prompt Engineering` → `Structured Outputs` → `Tool Calling` → `Function Calling` → `Streaming` → `Embeddings` → `Vector Databases` → `RAG` → `Context Management` → `Agent Loops` → `Memory` → `Evaluation`

The objective is to build systems that can **understand → reason → use tools → execute → evaluate** rather than simply generate text.
